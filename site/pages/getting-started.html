Getting started

Three steps: install, create a database, keep the key safe.

1. Install

Windows 10 / 11

Download the installer from the downloads page, verify its checksum, and run it. Choose per-user or per-machine installation. Windows already includes the Edge WebView2 runtime the window needs.

Linux

Download the archive, then:

tar -xzf Iceberg-{{version}}-linux-x64.tar.gz
cd Iceberg && ./install.sh
sudo apt install gir1.2-webkit2-4.1   # Debian/Ubuntu; Fedora: webkit2gtk4.1

Or run iceberg --browser to use your web browser as the window.

From source

Python 3.11-3.14: pip install -r requirements.txt then python webapp.py. Details in docs/SETUP.md.

2. Create your first database

  1. On the Welcome screen choose Create New Database.
  2. Enter the business name and address (they print on invoices) and your sales tax rate, or leave it at 0.00.
  3. Choose a filekey folder. The .icbkey written there is the only way to open your books - put it somewhere your backups cover, such as a thumb drive or a synced folder, and never in the same place as the database alone.
  4. Choose a receipts folder for receipt images and invoice PDFs, then select Create Database.

The dashboard opens with a standard chart of accounts (checking, cash, receivables, common expense categories, sales). Record a transaction with + New Transaction, add customers and services, and create an invoice.

3. Know where your files are

Tools → Where are my files shows the data folder (%LOCALAPPDATA%\Iceberg on Windows, ~/.local/share/iceberg on Linux) with your databases, backups, and logs. Iceberg saves automatically every five minutes when something changed, on every manual save, and when you close it. Backups are written on every save.

Troubleshooting

What you seeWhyWhat to do
The window is blank (Windows)The Edge WebView2 runtime is missing.Install the WebView2 Runtime from Microsoft, then start Iceberg again.
"No webview backend is installed" (Linux)WebKitGTK is not installed.sudo apt install gir1.2-webkit2-4.1 python3-gi, or start with iceberg --browser.
"The filekey does not match this database"A different .icbkey was selected, or the file is damaged.Select the key saved when the database was created. If the file is damaged, restore a backup (Tools → Restore from backup).
"Database not found"The .icb is not in the databases folder.Copy it into the folder shown under Tools → Where are my files.
"SAVE FAILED …" in the status lineDisk full, folder read-only, or the key file moved.Your books are still open in memory. Fix the cause and select Save again.
A form refuses to saveA field failed validation.The problem is written beneath the field in red; correct it and submit again.
Invoice PDF not writtenThe receipts folder no longer exists.Set it again under Tools → Database properties; the PDF is regenerated when you select View PDF.

Still stuck? Run the self-check from a terminal - Iceberg.exe --check on Windows, ./Iceberg --check on Linux - it lists what is missing with the fix for each item.

Report an issue

Open an issue at {{repo}}/issues. Please include:

  • Iceberg version (Tools → About, or Iceberg --version) and your operating system.
  • What you did, what you expected, and what happened - the text of any message in the status line.
  • The last lines of logs/iceberg.log from the data folder (Tools → Where are my files). The log contains no account numbers or amounts beyond what you typed into console-visible actions.

Please do not attach your .icb or .icbkey.
