# ST-029 — Getting started and support

- **Status:** Implemented
- **Priority:** P1
- **Area:** Support

## User story

As a new or existing user, I want setup guides, troubleshooting steps, and a clear way
to report issues so I can get started and resolve common problems.

## Acceptance criteria

- [x] `getting-started.html` covers install per platform, creating the first
      database, and file locations.
- [x] A troubleshooting table addresses common problems in plain language.
- [x] Instructions for reporting an issue state what to include and, importantly, what
      not to attach (e.g. no real business data/keys).
