# ST-030 — Project transparency

- **Status:** Implemented
- **Priority:** P1
- **Area:** Transparency

## User story

As a prospective user, I want to review the license, privacy and data-storage
practices, security guidance, and project status so I can understand how the software
and my accounting data are handled.

## Acceptance criteria

- [x] `about.html` states the MIT license.
- [x] Privacy and data-storage practices are explicit: local-only storage, encryption
      details, what is and is not encrypted, and the loopback-only local server.
- [x] Security guidance and current project status/roadmap are published, not hidden.

## Implementation evidence

`site/pages/` (about content), `LICENSE`.
